
# backend/ Ausgelagerte Funktionen

backend/ ist ein Abrechnungssystem : das frontend -Funktionen auslagert / nach Ausführung bepreist - und mit einem Wallet- Service bespricht

## Einheiten

- Einheit : 1 ₵ (Cent) ( entspricht 1 Euro Cent )
- Eurotrennzeichen : 1,00,00 ₵ / so dass klar der entsprechendeEurobetrag ersichtlich ist

## Preisliste

### Einzelabrechnungen

- 1 Zeichen tippen : 0,003 ₵
- Character/ Smiley einfügen über Button : 0,005 ₵
- Copy/ Paste : 0,005 ₵
- Undo : 0,005 ₵
- Redo : 0,005 ₵
- Instruction ausführen : 0,01 ₵
- Neue Datei erstellen : 0,01 ₵
- Neuen Vault erstellen : 0,1 ₵
- Vault Key erstellen : 0,01 ₵
- Vault Backup erstellen : 0,2 ₵

### Zeitnutzung

- Horizontales Layout / Stunde : 0,01 ₵
